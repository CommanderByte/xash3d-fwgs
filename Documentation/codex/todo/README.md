# Codex TODO Notes

This folder contains focused TODO lists derived from the modernization docs.

Use these files for implementation checklists that are more detailed than the
main `tasks.md` phase tracker, but still useful for auditability.

Documents:

- [android_assets_backend_todo.md](android_assets_backend_todo.md) tracks the
  Android asset backend migration after desktop backend patterns are stable.
- [archive_registry_todo.md](archive_registry_todo.md) tracks the
  filesystem-specific archive registry scaffold and follow-up work.
- [debugging_todo.md](debugging_todo.md) tracks remaining work for the modern
  debugging utility layer.
- [directory_backend_todo.md](directory_backend_todo.md) tracks the first
  modern filesystem backend pilot.
- [compatibility_facades_todo.md](compatibility_facades_todo.md) tracks
  legacy-facing ABI wrapper rules.
- [file_handle_todo.md](file_handle_todo.md) tracks future `file_t` operation
  migration.
- [filesystem_state_todo.md](filesystem_state_todo.md) tracks migration of
  `filesystem.c` global state.
- [game_hierarchy_todo.md](game_hierarchy_todo.md) tracks game directory and
  mount-order construction.
- [library_locator_todo.md](library_locator_todo.md) tracks `FS_FindLibrary`
  migration.
- [pak_backend_todo.md](pak_backend_todo.md) tracks the first archive backend
  migration candidate.
- [path_policy_todo.md](path_policy_todo.md) tracks path rejection and write
  path policy migration.
- [search_results_todo.md](search_results_todo.md) tracks `FS_Search` and
  `search_t` result assembly migration.
- [utilities_todo.md](utilities_todo.md) tracks shared utility work such as the
  generic ordered registry.
- [wad_backend_todo.md](wad_backend_todo.md) tracks WAD backend migration
  concerns.
- [zip_backend_todo.md](zip_backend_todo.md) tracks ZIP/PK3 backend migration
  concerns.
