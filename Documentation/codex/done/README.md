# Completed Codex Notes

This folder stores completed planning, TODO, and audit documents after their
implementation evidence has landed in `Documentation/codex/tasks.md`.

Keep active work in `Documentation/codex/todo/`. Move a document here only when
all checklist items in that document are complete or when the remaining work has
been moved into a newer active TODO.

## Folders

- [audit](audit/filesystem/README.md): completed implementation audit notes.
- [todo](todo/README.md): completed implementation checklists.
